# 视觉 → 电控 串口协议（v2，28 字节）

> 视觉侧：LicheeRV Nano（SG2002）。状态：**本协议待实现**（约 0.5 天）；联调可先用现有 ASCII 版，本文档是目标协议。

## 1. 物理层

| 项 | 值 |
|---|---|
| 接口 | UART，3.3V TTL，共地，TX/RX 交叉 |
| 格式 | 115200 8N1，无流控 |
| 视觉侧设备 | `/dev/ttyS1`（待对排针确认） |
| 发送节奏 | **固定 50Hz，有没有目标都发**（心跳） |

## 2. 帧格式（小端）

```
A5 5A | LEN | SEQ | CMD | 数据(21 字节) | CRC16
```

| 字段 | 值/说明 |
|---|---|
| `LEN` | 固定 `0x15`（21） |
| `SEQ` | 每发一帧 +1，0..255 回绕（**只用于丢包统计**，不参与控制） |
| `CMD` | `0x01` 控制帧 |
| `CRC16` | CCITT-FALSE：poly `0x1021`，init `0xFFFF`，不反射；小端；覆盖 `LEN` 到数据末尾（offset 2 ~ 4+LEN） |
| 帧总长 | **28 字节** |

## 3. 数据（21 字节）

| 偏移 | 类型 | 字段 | 单位 | 说明 |
|---|---|---|---|---|
| 0 | u8 | `detected` | — | 1 = 有目标；0 = 无 |
| 1 | f32 | `yaw` | 度 | 正 = 目标在光轴右侧（**瞄准点** = 引导灯上方装甲板中心） |
| 5 | f32 | `pitch` | 度 | 正 = 目标在光轴上方（**瞄准点** = 引导灯上方装甲板中心） |
| 9 | f32 | `vyaw` | 度/秒 | 角速度（前馈用） |
| 13 | f32 | `vpitch` | 度/秒 | 角速度（前馈用） |
| 17 | f32 | `dist` | 米 | 斜距；**`-1.0` = 无效** |

## 4. 使用规则

- `detected == 1`：角度可用。
- `detected == 0`：角度全为 0、`dist = -1.0`，**不要使用**。
- `detected == 0` 持续 **<80ms**：建议沿用上一帧角度（避免抖动）；**>200ms**：停止闭环/回中。
- 单帧 CRC 错：丢弃该帧，**不要重置角度状态**；`>300ms` 收不到帧：视为视觉掉线，停机。
- 角度范围约水平 ±32°、垂直 ±18°。

## 5. 示例（可直接当解析测试用例）

```text
A5 5A 15 07 01 01 A4 70 45 41 A4 70 B5 40 CD CC 34 42 CD CC 44 C1 1B 2F 5D 40 42 8E
→ SEQ=7 CRC=0x8E42 detected=1 yaw=12.34 pitch=5.67 vyaw=45.20 vpitch=-12.30 dist=3.456
```

```text
A5 5A 15 08 01 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 80 BF 99 7C
→ SEQ=8 CRC=0x7C99 detected=0 角度全 0 dist=-1.0（无目标心跳帧）
```

## 6. CRC16 参考代码（C）

```c
static uint16_t crc16(const uint8_t *p, uint32_t n) {
  uint16_t c = 0xFFFF;
  for (uint32_t i = 0; i < n; ++i) {
    c ^= (uint16_t)p[i] << 8;
    for (int b = 0; b < 8; ++b)
      c = (c & 0x8000) ? (uint16_t)((c << 1) ^ 0x1021) : (uint16_t)(c << 1);
  }
  return c;
}
/* 校验：crc16(buf+2, 3 + buf[2]) 与 buf[5+buf[2]] | buf[6+buf[2]]<<8 比较 */
```
